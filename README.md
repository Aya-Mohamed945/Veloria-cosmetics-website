# Veloria 🛍️
**Full-Stack E-Commerce Web Application**

## 📌 Overview
Veloria is a full-stack e-commerce web application designed to simulate a real online shopping experience. The project focuses on building a responsive and interactive frontend combined with a lightweight backend for handling data and dynamic content updates using PHP and JSON.

## 🚀 Features
- Responsive and modern user interface
- Dynamic product listing loaded from JSON files
- Interactive UI using vanilla JavaScript
- PHP backend for data handling and server-side logic
- JSON-based data storage for products and pricing
- Clean navigation and smooth user experience

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Data Storage:** JSON
- **Local Server:** XAMPP (Apache)

## ▶️ How to Run the Project Locally

1. Download and install **XAMPP**
2. Open the XAMPP Control Panel and start **Apache**
3. Navigate to the XAMPP installation directory:
C:\xampp\htdocs\
4. Copy the **Veloria** project folder and paste it inside the `htdocs` folder
5. Make sure the project folder name matches the URL path (e.g. `veloria`)
6. Open your browser and go to:
http://localhost/veloria
7. The website should now be running locally

> ℹ️ This project uses PHP for backend logic and JSON files as a data source, so it must be run on a local server environment and cannot be opened directly as static HTML files.

## 🎯 Purpose of the Project
This project was built to practice full-stack web development fundamentals, focusing on frontend–backend integration without using frameworks, and to strengthen understanding of PHP, JSON handling, and dynamic UI updates.

## 📂 Project Type
Full-Stack Web Application (Frontend + Backend)
